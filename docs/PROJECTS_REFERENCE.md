References: Claude iOS `1.261002.20 (37091698851)`, captured October 8, 2026 through iPhone Mirroring. Implemented from those observations: empty Projects, Pinned/Yours filter and Archived entry, educational introduction, Name/optional Goal/context/environment setup, icon/color/search picker, Repository/Google Drive context menu, Drive folder-link form, and Cloud/Default environment menu. The title-only validation was observed: a temporary nonempty Name enables the creation check before choosing an environment; clearing it disables the check. No original project was created.

`SessionState.projects` owns `ProjectState`. Route through `.openProjects`; `.projects(ProjectAction)` carries edits and host intents. `ProjectState.validatedDraft` trims Name/Goal without modifying visible draft text. `.create(draft)` does not create a project or clear the form. The integrating host may call `acknowledgeCreated(_:)` after accepting its request. Hosts may inject projects, suggested repository and environments; the populated-list fallback is functional but its visual design is unverified. Switching top-level routes preserves the normal conversation draft. Cancel clears the unsaved project; the introduction is skipped after its Continue action within the local session.

The icon picker uses SF Symbol approximations for most of its 70 visible entries and an original outline for the stacked Project mark. Source glyph identity, exact colors and the complete scrollable catalog are unresolved. Search uses local icon names rather than the vendor's search index. The selected color/icon are local draft state; picker Back discards unsaved icon changes. The educational miniature is rebuilt using fictional text rather than embedding a private screenshot; its exact illustration, font and animation are not established.

The Drive form never loads a folder. Its local enabled-state validation accepts an HTTPS `drive.google.com` URL with a nonempty `/folders/` component; only the source's empty disabled state was captured, so this URL rule is provisional. Repository selection, archived-project content, project creation progress/errors, populated project conversations and detail pages are unobserved. Buttons for unobserved destinations emit typed intents and identify the missing reference. Do not count these as complete visual implementations.

Nine state tests cover the introduction gate, cancellation, whitespace validation, host-only creation, context deduplication, environment allowlist, identity-preserving host acknowledgement, icon selection/search, injected filtering, and exclusive top-level navigation with draft preservation. UI and final build results are recorded in the top-level validation record after each scoped run.
